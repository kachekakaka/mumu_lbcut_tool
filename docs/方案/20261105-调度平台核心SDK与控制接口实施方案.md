## 1. 需求与设计背景

上层调度平台（Orchestrator）在纳管多模拟器并发录播任务时，需要以下三个关键维度的接口支撑：
1. **多模拟器实例纳管与故障隔离**：
   - 自动枚举宿主机上所有可用的 MuMu 模拟器实例（包括 vmindex、名称、开机状态、ADB 调试端口）；
   - 线程安全的实例槽位分配（`acquire`）与归还（`release`）；
   - 当 Worker 遇到致命阻断（如弹窗/登录阻断，返回 Exit Code 15）时，调度池必须自动将该实例标记为 `BLOCKED`，隔离该实例防止后续任务继续踩坑，并支持人工干预后一键恢复（`unblock`）。
2. **高并发直播间状态批量轮询**：
   - 针对运营提供的数十个目标主播（支持分享口令、短链、网页链接、纯房间号），以高并发线程池快速批量探测开播状态，耗时控制在秒级；
   - 自动对比前后两次扫描的状态差量，触发 `on_newly_live`（新开播）和 `on_newly_ended`（已下播）事件，驱动自动化派单。
3. **Worker 独立子进程控制与异步事件流消费**：
   - 以非阻塞方式异步读取 Worker stdout 输出的 NDJSON 事件流，避免标准输出管道缓冲导致跨进程死锁；
   - 实时派发事件回调（`on_event`），自动维护分段产物列表（`finished_segments`）与最新心跳（`latest_heartbeat`）；
   - 在 Windows 环境下支持通过 `CTRL_BREAK_EVENT` 进行确定性平滑停机（Graceful Stop），确保在录制切片尾部索引安全封装落盘后退出。

## 2. 模块架构与核心导出

调度层 SDK 位于 `src/orchestrator/`，统一通过 `src/orchestrator/__init__.py` 导出：

```text
src/orchestrator/
├── __init__.py           # 顶层统一导出接口
├── models.py             # 实体定义 (InstanceStatus, InstanceSlot, JobStatus, WorkerLaunchSpec)
├── instance_pool.py      # 线程安全实例池 (InstancePool)
├── worker_process.py     # Worker 独立子进程异步句柄 (WorkerProcessHandle)

```

## 3. 核心接口与调用示例

### 3.1 实例池管理 (`InstancePool`)

```python
from src.orchestrator import InstancePool, InstanceStatus

# 1. 初始化并刷新实例
pool = InstancePool()
slots = pool.refresh()
print(f"检测到实例总数: {len(slots)}")

# 2. 申请可用实例（支持优先指定 vmindex）
slot = pool.acquire(target="https://v.douyin.com/xxxxx/", job_id="job_001", preferred_vmindex=0)
if slot:
    print(f"成功获取实例: #{slot.vmindex} ({slot.name})")

# 3. 归还实例（若退出码为 15，自动触发隔离）
pool.release(vmindex=slot.vmindex, exit_code=15, reason="遇到账号登录验证阻断")

# 4. 查看当前池快照
summary = pool.get_summary()
print(summary)  # {'total': 3, 'idle': 2, 'busy': 0, 'blocked': 1, 'offline': 0}

# 5. 人工在模拟器登录处理完毕后，解除隔离
pool.unblock(vmindex=slot.vmindex)
```

### 3.2 批量开播差量扫描 (`RoomScanner`)

```python
from src.orchestrator import RoomScanner

scanner = RoomScanner()
targets = [
    "74400659583",
    "https://v.douyin.com/iANgXXXX/",
    "67909384752",
]

# 方式 A：单次并发批量探测
results = scanner.scan(targets, max_workers=8)
for res in results:
    print(f"房间: {res.target} | 在播: {res.is_live} | 标题: {res.title} | 主播: {res.nickname}")

# 方式 B：差量监听（自动比对上次状态，触发新开播或下播回调）
def on_live(result):
    print(f"【新开播】{result.nickname} 正在开播，准备分配 Worker 录制！")

def on_ended(result):
    print(f"【已下播】{result.nickname} 直播已结束。")

scanner.scan_and_notify(targets, on_newly_live=on_live, on_newly_ended=on_ended)
```

### 3.3 Worker 进程控制与事件监听 (`WorkerProcessHandle`)

```python
from pathlib import Path
from src.orchestrator import WorkerProcessHandle, WorkerLaunchSpec

spec = WorkerLaunchSpec(
    vmindex=0,
    target="74400659583",
    output_dir=Path("d:/recordings/74400659583"),
    segment_duration_sec=1800,  # 30 分钟分段
    overlap_duration_sec=3.0,   # 3 秒无损交叉重叠
    window_mode="bottom",       # 窗口放置在最底层，不影响前台工作
    target_x=0,                 # 可选窗口坐标
    target_y=0,
)

def handle_event(evt: dict):
    evt_type = evt.get("event")
    if evt_type == "segment_finished":
        print(f"分段落盘: {evt['path']}, 时长: {evt['duration_sec']}s")
    elif evt_type == "heartbeat":
        print(f"Worker 心跳: 帧率 {evt.get('render_fps')}, 已录制 {evt.get('recorded_duration_sec')}s")

worker = WorkerProcessHandle(spec=spec, on_event=handle_event)
worker.start()

# 轮询状态或等待业务信号
# ...
# 优雅停机：发送中断信号并等待其安全封口落盘退出（默认 30 秒超时）
return_code = worker.stop(timeout_sec=30.0)
print(f"Worker 已安全退出，Exit Code: {return_code}")
print(f"本次录制生成的所有分段: {worker.finished_segments}")
```
