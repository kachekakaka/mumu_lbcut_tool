# 0021 控制台切片支持在录制机桌面定位高亮，内网设备均可触发

## Status
accepted（2026-11-13 访谈确定；2026-11-14 澄清启动回执与连接状态边界）

## Context
控制台切片表格（`/segments` 及任务详情）此前仅支持复制文件绝对路径，运维人员在录制机本地排查或复核切片时需手动打开资源管理器并粘贴路径翻找文件。控制台支持局域网内第二设备及手机访问（[ADR 0016](0016-console-frontend-separate-build-and-private-network-access.md)），需要明确该操作在多端访问下的能力边界、安全范围与交互体验。

## Decision
1. **实体路由与工作区录像根约束**。采用 `POST /api/segments/{job_id}/{segment_index}/open-folder`。后端按切片记录定位文件，校验工作区登记的录像根和该切片的正式归档或暂存目录。历史录像根离线时返回原路径供核对。[接口契约](../控制台接口契约.md)
2. **桌面高亮定位与目录降级**：后端启动 Windows 资源管理器，发送文件定位请求；若文件不存在，则改为请求打开父目录。启动异常必须返回失败，启动调用正常返回也不保证桌面已展示或完成高亮，响应语义以[接口契约第 8 节](../控制台接口契约.md#8-切片桌面定位desktop-reveal)为准。
3. **内网设备均可触发，动作交给录制机文件管理器**：遵循控制台纯内网/私网运行且无公网暴露的安全基线（[ADR 0016](0016-console-frontend-separate-build-and-private-network-access.md)），放行所有可信内网客户端。手机端不下载文件；录制机需有可用的交互桌面会话，SSH/服务环境的可见效果需单独验收。
4. **设备区分反馈与前端防抖**：提示已发送请求并请用户在本机或录制机桌面确认。断线及连接未确认时禁用打开目录，复制仍可用；连接恢复后可操作，不依赖调度器运行。请求期间及完成后的短暂防抖期禁用同表格的打开目录操作。

## Considered Options
- **严格限制仅 127.0.0.1 回环访问，手机端禁用**：可防止远程误触，但无法满足运维人员手持手机查看控制台时远程唤起录制机屏幕展示文件的实际需求。
- **提供切片文件 HTTP 下载而不是桌面打开**：高清切片动辄数 GB，局域网 HTTP 全量下载会抢占录播带宽与磁盘 I/O，且脱离了录制机本地运维的初衷。
- **通用文件路径接口 `POST /api/fs/open-folder` 传 `path`**：容易留下路径遍历和命令注入漏洞，改为切片实体主键寻址安全边界最清晰。
