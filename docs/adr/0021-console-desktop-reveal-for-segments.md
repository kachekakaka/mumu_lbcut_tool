# 0021 控制台切片支持在录制机桌面定位高亮，内网设备均可触发

## Status
accepted（2026-11-13 访谈确定）

## Context
控制台切片表格（`/segments` 及任务详情）此前仅支持复制文件绝对路径，运维人员在录制机本地排查或复核切片时需手动打开资源管理器并粘贴路径翻找文件。控制台支持局域网内第二设备及手机访问（[ADR 0016](0016-console-frontend-separate-build-and-private-network-access.md)），需要明确该操作在多端访问下的能力边界、安全范围与交互体验。

## Decision
1. **实体路由与输出目录白名单保护**：采用 `POST /api/segments/{job_id}/{segment_index}/open-folder`。接口不接收前端传入的任意路径，后端根据已登记的切片记录定位文件，且严格校验解析后的绝对路径落在当前配置的录像输出目录（`output_dir`）白名单内，防止任意系统路径遍历与越权执行。
2. **桌面高亮定位与优雅降级**：后端以异步非阻塞子进程调用 Windows 资源管理器 `explorer.exe /select,"<file_path>"`，直接在录制机桌面上弹出并高亮选中目标切片 MP4；若切片已被移动或文件不存在，则降级为仅打开其所在的上层目录。
3. **内网设备均可触发，动作发生在录制机桌面**：遵循控制台纯内网/私网运行且无公网暴露的安全基线（[ADR 0016](0016-console-frontend-separate-build-and-private-network-access.md)），放行所有可信内网客户端（包括手机、第二设备）调用该接口。动作物理发生在录制机桌面会话中，手机端不下载文件。
4. **设备区分反馈与前端防抖**：前端提供短暂防抖与 Loading 态，防止连击产生多窗口风暴；若检测为非本机（手机/局域网 IP）访问，点击成功后明确提示“已在录制机桌面打开所在目录”，本机访问提示“已打开所在目录”。

## Considered Options
- **严格限制仅 127.0.0.1 回环访问，手机端禁用**：可防止远程误触，但无法满足运维人员手持手机查看控制台时远程唤起录制机屏幕展示文件的实际需求。
- **提供切片文件 HTTP 下载而不是桌面打开**：高清切片动辄数 GB，局域网 HTTP 全量下载会抢占录播带宽与磁盘 I/O，且脱离了录制机本地运维的初衷。
- **通用文件路径接口 `POST /api/fs/open-folder` 传 `path`**：容易留下路径遍历和命令注入漏洞，改为切片实体主键寻址安全边界最清晰。
