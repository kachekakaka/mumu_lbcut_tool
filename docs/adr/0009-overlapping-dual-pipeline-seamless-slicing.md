# 0009 Overlapping Dual-Pipeline Seamless Slicing

为了消灭周期性切片轮转导致的 2.5 秒物理音画断层（F-09），系统采用双管线交叠切片（Overlapping Dual-Pipeline）架构。在到达切片周期前预设安全窗口（3~5秒），先通过独立 ADB 反向端口池拉起下一代切片管线，待确认新切片出流后优雅关停旧切片。该决策接受切片间秒级冗余重叠（Overlap），以短时模拟器双路编码为代价，实现切片交接的零内容丢失。

## Status
partially superseded：默认路径由 [ADR 0012](0012-continuous-capture-segment-muxer.md) 取代；旧双管线仅保留为显式对照诊断。

## Considered Options
- **串行停止后重启（原 F-09）**：交接存在约 2.5 秒物理黑屏断音，虽实现简单但存在内容丢失。
- **内存分流/单一长管线多路复用**：需要深度定制魔改 scrcpy C 代码或引入高风险的流媒体转发进程，开发与内存泄露风险极高。
- **双管线交叠并行（本决策）**：利用 Android 15.0 天然支持的音视频并发捕获能力，通过双端口池与先启后停实现零丢帧无缝切片。


## 2026-11-05 最小闭环交付边界

该日期交付曾默认 `overlap_duration_sec=0.0`、采用串行切片；2026-11-06 的当前默认已改为持续采集独立分装。双管线交叠保留为显式可选能力，已经增加交叠中停止、主管线崩溃、次管线失败的隔离回归，但不能替代 MuMu 同时采集和真实媒体时间码验证。本文中的无缝目标不构成零缺口实测承诺；当前操作和验收范围见 [最小调度运行说明](../最小调度运行说明.md)。
