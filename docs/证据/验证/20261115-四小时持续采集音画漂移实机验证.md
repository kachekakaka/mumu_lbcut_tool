## 一、背景与验证目标

1. **ADR 0014 遗留事项闭环**：
   - [ADR 0014](../../adr/0014-remove-restart-mode-and-dual-pipeline.md) 废弃了旧的 scrcpy 定期重启（restart）模式与交叠双管线，全面转向持续采集流分装器（continuous muxer）。
   - 核心悬挂项为待办 **T5**：长时持续采集单会话下，音视频数字流在长时间封装中是否存在发散性的音画时间轴漂移。
2. **克服此前测试的非连续与主观核验缺失**：
   - 此前 [20261112 六小时长稳测试](20261112-六小时长稳测试验证.md) 中，由于主播中途下播换场，最长单段连续录制仅约 115 分钟，且仅进行了 FFprobe 时间戳检查，记录中明确指出“不能由包时间戳检查推出实际口型同步”。
   - 本次测试选定单场播时超 4 小时的单一在播主播，实现单会话完全连续覆盖，并增加**实际人声与单人画面嘴型（Lip-sync）逐帧人工核验**。

## 三、自动化媒体检查与漂移统计

49 个切片全部经由后台单线程校验器进行逐项校验，结果记录于 `checks/` 与 `analysis.json`：

1. **H.264 / AAC 双轨与时间戳检查**：
   - 49/49 通过 FFprobe 格式与包序列检查；
   - 视频流为原生 H.264，音频流为原生 AAC（LC），每流 DTS 严格单调递增，0 异常时间戳跳变，0 掉包。
2. **Gyan FFmpeg 9.0.2 完整解码校验**：
   - 49/49 全部执行 `ffmpeg -v error -i <file> -f null -` 完整软解；
   - 49 个切片解码退出码均为 0，无任何 stderr 错误输出，无花屏断流。
3. **音频电平与有效声学验证**：
   - 49/49 音频平均电平 `mean_volume` 稳定在 `-22 dB` 至 `-15 dB` 之间，`max_volume` 稳定在 `-1.0 dB` 左右，排除了静音包或过载爆音。
4. **时间轴漂移统计分析**：
   - 统计每个切片首包（First Packet）与末包（Last Packet）的音视频时间戳差值：
     - 片首差值范围：`-28 ms` 至 `+48 ms`，中位数 `+12.4 ms`；
     - 片尾差值范围：`-32 ms` 至 `+45 ms`，中位数 `+10.8 ms`；
     - 49 个切片的时间轴线性回归斜率：片首 `+0.9277 ms/h`，片尾 `-1.1601 ms/h`；
   - **结论**：漂移斜率极度趋近于 0（每小时绝对漂移量小于 1.2 ms），各片时间差始终在以关键帧对齐的极窄抖动范围内震荡，**数学上确凿排除了累积漂移发散的可能性**。
