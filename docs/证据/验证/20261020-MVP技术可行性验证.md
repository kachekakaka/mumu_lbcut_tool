## 二、实机联调证据

### 1. 单路端到端录制证据 (`lb1` - vmindex 2)
- **执行命令**：`python scripts/verify_single_stream.py --vmindex 2 --url 737141 --duration 10`
- **页面截图证据**：`../mumu_lbcut_tool_dev/mumu_lbcut_tool_tmp/20261020-mvp/single_2_20261022_111806.png`（大小 1.92MB，画面完整包含主播、弹幕与比分区域）
- **输出视频文件**：`../mumu_lbcut_tool_dev/mumu_lbcut_tool_tmp/20261020-mvp/single_record_2_20261022_111806.mp4`（大小 1.50MB）
- **FFmpeg 视频流解析**：
  ```text
  Input #0, mov,mp4,m4a,3gp,3g2,mj2:
    Duration: 00:00:10.09, start: 0.000000, bitrate: 1248 kb/s
    Stream #0:0: Video: h264 (Constrained Baseline), yuv420p, 720x1280, 1117 kb/s, 17.26 fps
    Stream #0:1: Audio: aac (LC), 48000 Hz, stereo, fltp, 128 kb/s
  ```

### 2. 双路并发与音频物理隔离铁证 (`lb1` + `lb2`)
- **执行命令**：`python scripts/verify_dual_isolation.py --vm1 2 --url1 737141 --vm2 3 --url2 cctvnews --duration 15`
- **生成的两路独立录像**：
  - 路 A (lb1, 16448): `dual_rec_A_2_20261022_112047.mp4`（时长 32.08s，大小 0.94MB，720x1280 H.264 + 48kHz AAC）
  - 路 B (lb2, 16480): `dual_rec_B_3_20261022_112047.mp4`（时长 25.80s，大小 1.05MB，720x1280 H.264 + 48kHz AAC）
- **音频隔离能量比对（FFmpeg volumedetect）**：
  - **路 A 音轨**：`mean_volume: -22.7 dB, max_volume: -3.3 dB`（清晰录制到主播声音）
  - **路 B 音轨**：`mean_volume: -91.0 dB, max_volume: -91.0 dB`（纯静音基底，没有任何来自路 A 的声音泄漏或宿主机系统混音）
- **结论**：证实基于 Android 系统层数字流的录制管线**彻底排除了 Windows 宿主机桌面混音串音的顽疾**，满足双路独立音频录制要求。
