## 1. 修正内容

1. 文件管理器启动异常由桌面辅助层向上传递，API 记录完整异常并返回 HTTP 500 `desktop_open_failed`；不能继续返回 `succeeded` 或 `revealed`。
2. 成功响应仅表示启动请求已发出，定位/目录模式字段不充当桌面回执；本机与远程提示均要求用户到对应桌面确认。
3. 连接未知或断线时禁用打开目录，处理函数也检查连接；复制保持可用。恢复连接后可操作，不要求调度器正在运行。请求期间及完成后 1.5 秒内，同一表格的操作均禁用。
4. 本次在 `5856fe5` 上只补齐异常边界：桌面启动调用内的 `Exception` 统一转换为 `desktop_open_failed`，含非 `OSError` 异常；查询、路径解析与白名单校验保持在捕获范围外，不拦截 `KeyboardInterrupt`、`SystemExit` 等进程控制异常。同步澄清接口契约，未修改前端或其他运行逻辑。
