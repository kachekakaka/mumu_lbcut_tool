# 稳定渲染默认与 Worker 日志落盘验证

- 日期：2026-11-11。
- 受测代码：`b635fb3` 之上的未提交工作区改动，对应[待办](../../待办.md)原 K8、K9、K11 与 K12 的测试隔离部分。
- 环境：笔记本 Windows / MuMu 实例 2（Android 15，adb 16448）/ scrcpy 5.0.1 / 严格身份模式 / 抖音无登录。
- 外部材料：笔记本仓库同级 `mumu_lbcut_tool_dev/mumu_lbcut_tool_tmp/20261111-k9-stable-short-01/`（首次失败）、`20261111-k9-stable-short-02/`（通过；含 `worker.log`、`stdout.ndjson`、录像）；全量测试输出 `pytest_k8b.txt`。

## 1. 改动

| 事项 | 改动 |
| --- | --- |
| 渲染模式 | Worker 录制前调优时执行 `MuMuManager setting -k renderer_mode -val dx`，MuMu 写入“稳定”模式（`render.mode.stable`），下次开机生效 |
| Worker 运行日志 | Worker 新增 `--log-file`，自己把运行日志追加写入文件；调度器传入 `events/<job_id>.log`，主控退出后仍能继续记录 |
| 对账结束时间 | 重启对账时任务 `ended_at` 取 NDJSON 终止事件的 `timestamp`，没有则为对账时刻；退避仍从对账时刻起算 |
| 测试隔离 | `test_07` 替换 `DependencyManager`，不再检查或下载 scrcpy |

## 2. 自动化测试

全量 `py -3.11 -m pytest -q`：281 passed。新增或修改的断言：渲染模式命令；`--log-file` 写入日志且运行结束后移除日志处理器；真实子进程命令行带 `--log-file`；调度器给 Worker 的日志路径为 `events/<job_id>.log`；对账后 `ended_at` 等于终止事件时间。

## 3. 实例 2 短测

目标：李若暄，web_rid `xxuan0222`，room_id `7706779177160100646`，UID `995491988645881`。Worker 直接运行，`--segment-duration 120 --total-duration 300`。

**第一次（失败，与本次改动无关）**：MuMu 主程序未运行，Worker 先拉起主程序，5 秒后启动实例时 MuMuManager 返回 `-503 mainnx connect failed`，60 秒内实例未启动，以 20 退出，没有开录。该次运行的完整日志已写入 `worker.log`。冷启动主程序后立即启动实例失败的问题此前未记录，见[待办](../../待办.md) K13。

**第二次（通过）**：主程序已在运行。实例 49 秒开机，严格身份核验通过（`live_fragment_arguments` 证据，room_id 与 UID 均匹配），14:59:55 开录、15:04:53 截止，退出码 0（`completed`）。

| 切片 | 时长（秒） | 音画时长差（秒） | 完整解码 |
| --- | --- | --- | --- |
| 1 | 122.36 | 0.012 | 退出码 0 |
| 2 | 119.17 | 0.021 | 退出码 0 |
| 3（末片） | 58.44 | 0.063 | 退出码 0 |

合计约 300 秒，无多余尾片。解码输出只有 Null muxer 的 DTS 量化警告（[已排除](20261108-截图容错修复与15分钟实机验证.md#4-已排除不再调查)）。实例配置 `customer_config.json` 中渲染为 `render.mode.stable`。

录制期间帧率在 9～18 fps 之间，第 1、2 片打了 `low_frame_rate` 标记（与 [K3](../../待办.md) 的笔记本显卡降频现象一致）；第 2、3 片因主播画面静止打了 `static_picture` 标记。本次没有渲染器崩溃。

`worker.log` 带日期时间，包含导航、身份取证、scrcpy 输出（含停止时预期的 `Failed to write trailer`）与状态迁移，与 stderr 逐行对应（各 24 行）。手工运行时 stderr 按系统默认编码（GBK）写出；调度器启动 Worker 时设置了 `PYTHONIOENCODING=utf-8`，日志文件始终是 UTF-8。
